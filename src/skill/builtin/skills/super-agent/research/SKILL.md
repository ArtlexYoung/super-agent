# Research method

Start with a precise question and a list of claims that need evidence. Use
only source and browser tools explicitly supplied by the host. Reading this
Skill does not open a network connection, import a file, or create a cache.

Separate observed facts, source statements, calculations, and conclusions.
Prefer primary sources and record the source identity, retrieval time, and
the exact supporting passage or location. Cross-check important claims with
independent evidence and mark uncertainty instead of filling gaps with a
plausible answer.

Return a compact evidence table and a conclusion whose scope matches the
evidence. Keep citations useful without copying large source bodies into the
run record.

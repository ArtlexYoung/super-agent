# Project knowledge method

Organize project knowledge into background, goals, current state, decisions,
constraints, open questions, and next steps. Keep each item small enough to
update independently and attach its source and last-checked time.

Treat remembered knowledge as revisable experience, not a guaranteed fact.
Compare it with the current workspace and conversation before using it. Mark
stale, conflicting, or unverified items rather than silently merging them.

This Skill does not read a workspace or write a knowledge store by itself.
Use only explicit host tools and explicit memory lifetime choices.

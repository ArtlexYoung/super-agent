# Project context method

Before a substantial task, summarize only the context needed for the next
decision: objective, known constraints, current evidence, completed work,
risks, and the next verifiable step. Update an item only when new evidence
changes it, and preserve the previous decision when it remains valid.

Keep transient observations in the current conversation. Promote only
abstract, important, stable, or habitual project knowledge to long-term
memory, with a reason and source reference. Forget or revise obsolete items
explicitly.

# 评测 / Benchmarks

## 离线门禁 / Offline Gate

仓库提供不调用远程模型的评测清单，使用 `SUPER_AGENT_PROVIDER=mock`，验证真实 CLI、结构化输出和工作区无变化。

The repository includes an offline manifest that calls no remote model. It uses `SUPER_AGENT_PROVIDER=mock` and verifies the real CLI, structured output, and an unchanged workspace.

```bash
PYTHONPATH=src python3.11 scripts/run_benchmark.py \
  --manifest examples/offline-gate-benchmark.json \
  --output /tmp/super-agent-benchmark
```

输出目录包含摘要、每个任务的结果哈希和受限的输出内容。评测器限制超时、捕获大小和工作区范围，避免评测本身产生无界副作用。

The output contains a summary, result hashes, and bounded task output. The runner limits timeouts, capture size, and workspace scope so the benchmark itself has bounded effects.

## 发布结果 / Published Results

README 中的 HumanEval+ 和 LiveCodeBench 数字是历史对照报告，不是每次本地门禁自动生成的结论。重新评测时应保存模型、版本、清单哈希、运行时间和失败任务。

The HumanEval+ and LiveCodeBench numbers in the README are historical comparison reports, not claims generated by every local gate. New evaluations should save model, version, manifest hash, timestamp, and failed tasks.

不要把评测通过等同于模型可靠性；评测只覆盖清单声明的行为。

Do not equate a passing benchmark with model reliability; a benchmark covers only the behavior declared by its manifest.

# Runtime Proofs

The [v0.0.61 unified proof](v0.0.61.md) is the maintained proof for the current Runtime.
It covers user-scoped model Skills and credentials, automatic scheduling, progressive
disclosure caches, memory organization and forgetting, mandatory Safety, canonical
events, and user-only Skill evolution.

Earlier reports are immutable release snapshots. They document the behavior proved at
their corresponding tags, but their generators are not compatibility targets during the
breaking `0.0.x` series. Run an earlier generator from its matching Git tag when
reproducing that release.

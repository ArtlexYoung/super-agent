# v0.0.41 Task and Evolution Proof

This experiment verifies that model scheduling, evidence isolation, observability, and automatic Skill evolution use the normal Runtime path. It is a deterministic mechanism proof, not a benchmark of model answer quality.

## Reproduce

From the repository root at tag `v0.0.41`:

```bash
PYTHONPATH=src python3 docs/experiments/run_v0_0_41.py \
  --output docs/experiments/v0.0.41.json
```

The script uses temporary JSONL storage and the built-in deterministic Provider. It requires no network access, API key, optional dependency, or persistent database. The report excludes temporary paths, run IDs, evolution IDs, candidate IDs, timestamps, and secrets, so identical proof inputs produce identical JSON.

## What Is Checked

- Two real `model` Skills declare different purposes, strengths, quality, and latency traits.
- The normal `Agent.run()` path selects `model:fast` for an answer task and `model:deep` for an analysis task.
- Canonical run events project the schedule reasons, completed model calls, token estimates, latency, cost, routing evidence, Skill freshness, and related evolution state.
- Routing evidence written for user `alpha` is invisible to user `beta` on the same Agent.
- Routing evidence written by `scheduler-a` is invisible to `scheduler-b` for the same user and storage backend.
- A failed real task creates evaluation evidence for an Agent-owned Skill, automatically creates and evaluates a candidate, and promotes it.
- A second failed task monitors the promoted version as a regression, automatically restores the parent version, and exposes the `rolled_back` status on that regression run.

## Committed Result

All nine checks passed. The answer and analysis tasks produced two completed observable model calls and two isolated routing records: `answer:model:fast:1` and `analysis:model:deep:1`. The evolution loop used one `skill_evolution` model call and one `skill_evaluation` model call, promoted a candidate with score `1.0`, then recorded `rolled_back`, exposed that status through the regression run insight, and restored the original `SKILL.md`.

The committed [JSON report](v0.0.41.json) is the machine-readable result. Its `input_sha256` covers the prompts, model traits, and parent/candidate instructions used by the proof.
